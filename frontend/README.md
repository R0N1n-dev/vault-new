# Coffer frontend

Vue 3 + TypeScript UI for Coffer. See the [project README](../README.md) for the
full picture and [docs/FORMAT.md](../docs/FORMAT.md) for the vault file format.

```sh
npm install
npm run dev        # browser preview on http://localhost:3004
npm run typecheck  # vue-tsc --noEmit
npm run build      # typecheck + production bundle into dist/
npm run smoke      # drives the browser-preview backend and asserts the crypto
```

Inside the Wails window `window.go.main.App` is present and `src/lib/backend.ts`
resolves to the Go implementation. In a plain browser it falls back to
`src/lib/demoBackend.ts`, which is a real WebCrypto vault kept in
`localStorage` — clearly labelled in the UI, and never used by the packaged app.

`wailsjs/go/**` is generated by `wails dev` / `wails build`; only the runtime
shim is tracked here.
